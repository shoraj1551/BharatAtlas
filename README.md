# BharatAtlas 🇮🇳

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Status](https://img.shields.io/badge/Status-Early%20Development-orange)](https://github.com/shorajtomer/BharatAtlas)

BharatAtlas is an AI-powered, zoomable digital atlas of India that provides structured, reliable insights from national to village level.

## 🎯 Vision

To make every place in India understandable, comparable, and actionable.

## ✨ Key Features

- **Multi-Level Navigation**: State → District → Tehsil → Village zoom interface
- **AI-Generated Profiles**: Comprehensive place descriptions and insights
- **Opportunity Detection**: Business & development opportunity identification
- **Data Confidence Layers**: Verified + inferred data with transparency

## 📊 Status

🚧 **Early-stage development** (MVP planning)

## 🗂️ Project Structure

```
bharat-atlas/
├── docs/              # Project documentation
├── backend/           # API, services, models, database
├── frontend/          # Map interface, components, pages
├── data/              # Raw, processed, and reference data
└── scripts/           # Data ingestion and AI generation
```

## 🌿 Branch Strategy

| Branch | Purpose | Stability |
|--------|---------|-----------|
| `main` | Production-ready code | 🟢 Stable |
| `uat` | User acceptance testing | 🟡 Testing |
| `dev` | Active development | 🔴 Unstable |

**Merge Flow**: `feature` → `dev` → `uat` → `main`

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/shorajtomer/BharatAtlas.git
cd BharatAtlas

# Checkout dev branch for development
git checkout dev

# Install dependencies (when available)
npm install

# Run development server (when available)
npm run dev
```
